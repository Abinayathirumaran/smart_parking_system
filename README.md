# Slotify - Smart Parking System

Slotify is a modern, responsive full-stack parking lot management web application designed to simplify slot tracking, real-time availability, and administrative management.

---

## 🚀 Features

### 👨‍💼 For Administrators
* **Management Panel:** Create and configure parking lots dynamically with customizable floor and slot counts.
* **Auto Slot Generator:** Easily generate anywhere from 1 to 5 floors with 1 to 20 slots per floor.
* **Status Badges:** Manage slot states with real-time indicators for **Available**, **Maintenance**, and **Removed** statuses (maintenance slots instantly highlight in yellow).
* **Quick Navigation:** Instant page-scroll mapping when clicking "Manage Slots" on a parking lot card.
* **Live Analytics:** Track parking insights and usage metrics broken down into separate categories.

### 👤 For Users
* **Dynamic Dashboards:** Real-time live data updates for parking availability.
* **Favourites Section:** Save preferred parking locations for quick access.
* **Integrated AI Chatbot (Dialogflow):** Built-in Google Dialogflow messenger bot available at the bottom-right of every page for instant assistance and slot inquiries.
* **Responsive Layout:** Optimized for seamless viewing across both desktop and mobile devices.

---

## 🛠️ Tech Stack

* **Frontend:** React.js, React Router, Tailwind CSS
* **Authentication:** JWT (JSON Web Tokens), `jwt-decode`, LocalStorage
* **Chatbot Integration:** Google Dialogflow Messenger Web Component (`df-messenger`)
* **Deployment Ready:** Configured for static hosting platforms like Render
